FFmpeg audio filters for Jedflix

This application includes a replacement libavfilter.so compiled from unmodified
FFmpeg 8.1 source, with audio filters enabled for the player's Night audio mode.

Build recipe in the Jedflix project: scripts/build-audio-filters.py
Build instructions and dependency/toolchain pins: docs/audio-native-build.md
Build commands:
  python3 scripts/build-audio-filters.py --abi x86_64
  python3 scripts/build-audio-filters.py --abi arm64-v8a

The build uses Android NDK r28c, Android API 23, shared libraries, GPL/version3,
and a 16 KB ELF page alignment. No FFmpeg source files are modified. The enabled
optional filters are acompressor, alimiter, volume, aformat, aresample, pan, anull.
The existing application's original avutil/swresample dependencies are retained.
